# Солонго нүдний эмнэлэг (Solongo Eye Hospital)

Монгол хүний эрүүл нүдний төлөө — Солонго нүдний эмнэлгийн албан ёсны веб платформ.

## Үндсэн онцлог, боломжууд

1. **Бүрэн маршрут, хуудасны бүтэц (SPA Navigation):**
   - `/` — Нүүр хуудас (Уриа, давуу талууд, үйлчилгээ, эмч нарын танилцуулга, сүүлийн үеийн мэдээ, интерактив 20-20-20 дасгалын таймер)
   - `/about` — Бидний тухай (Алсын хараа 2023-2034, үнэт зүйл, аюулгүй байдал, ариутгалын стандарт)
   - `/about/history` — Түүхэн замнал (2012 оноос өнөөг хүртэлх хөгжлийн гол үе шатууд)
   - `/services` — Эмнэлгийн үйлчилгээ (Үзлэг оношилгоо, мэс засал, хүүхдийн нүд, хараа зүйн ангилалтай хайлт)
   - `/services/:slug` — Үйлчилгээний дэлгэрэнгүй хуудас (Шинж тэмдэг, хийгдэх шинжилгээ, бэлтгэл, ЭМД-ын 75% хөнгөлөлт, түгээмэл асуултууд)
   - `/doctors` — Эмч, мэргэжилтнүүд (БНЭУ-ын зөвлөх профессор Dr. R.P. Singh болон мэргэшсэн эмч нар, туршлага, үзлэгийн хуваарь)
   - `/news` — Мэдээ, зарлал (Ангиллаар шүүх, хайх)
   - `/news/:slug` — Мэдээний дэлгэрэнгүй унших хуудас
   - `/advice` — Эрүүл мэндийн зөвлөгөө (20-20-20 дүрэм, болор цайлт, глауком, хүүхдийн нүд хамгаалал)
   - `/branches` — Салбар эмнэлгүүд (Төв эмнэлэг - Санрайс хотхон, UBH салбар, Солонго хараа заслын төв - MPM цогцолбор)
   - `/contact` — Холбоо барих & Санал хүсэлтийн баталгаажсан маягт
   - `/privacy` — Хувийн мэдээлэл, эмнэлгийн нууцлалын бодлого

2. **Бодит цаг захиалгын урсгал (Medsoft цахим систем):**
   - Эмнэлгийн албан ёсны цахим цаг захиалгын холбоос: `https://solongo.medsoft.care:3001/`
   - Шууд лавлах утсаар холбогдох: `7705-6699`, `7706-6699`, `7701-6699`

3. **Монгол кирилл үсгийн цэвэр дүрслэл (Typography):**
   - Кирилл үсгийн 'ү', 'ө' тэмдэгтүүдийг бүрэн алдаагүй дэмждэг `Inter` болон `Roboto` фонтын багц

4. **Аюулгүй байдал & Санал хүсэлтийн маягт:**
   - Нэр, холбоо барих утас/и-мэйл, мессеж, нууцлалын зөвшөөрлийн талбаруудын нарийвчилсан шалгалт (validation)
   - Unit test-ээр баталгаажсан (`src/utils/validation.test.ts`)

## Суулгах болон ажиллуулах заавар

### Шаардлагатай орчин:
- Node.js v20 эсвэл v22+
- npm v10+

### Хөгжүүлэлтийн горимд ажиллуулах:
```bash
npm install
npm run dev
```
Вебсайт `http://localhost:3000` хаяг дээр ажиллана.

### Unit тестүүд ажиллуулах (Node 22 native test runner):
```bash
node --test src/utils/validation.test.ts
```

### Production Build хийх:
```bash
npm run build
```
Build файлууд `dist/` хавтсанд үүснэ.
